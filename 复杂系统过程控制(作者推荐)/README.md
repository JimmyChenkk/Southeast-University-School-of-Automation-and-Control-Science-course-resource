**首先说简答题，哪些英语是必须要记住的？你语法差不成句没关系！要的就是一个字一个字往外蹦，这就够了，卷子最前有五六道简答，问你过控关注的指标，首先你题目要读对，问的是object，你能反应过来问的所谓对象就是温度压力流量液位成分吗？这五个单词要会，再比如写一下静态1个和动态3个性能指标，这里面衰减比attenuation ratio大概率是生词吧，要背出，然后常识性的4-20mA和20-100kPa知道这俩直接写上即可，你看，你如果不会英语也不影响的，最后两线制三线制这种关键的示意图手绘要绘画，简单说一下原因，不就是两线制由于long distance有resistance造成的误差然后三线制解决了这个issue，solve了这个error吗，大胆写，大差不差你就是库库拿分；**

**然后进入大题，绕不过去的建模题，复习的时候你肯定很慌，“这谁写的出方程式”、“这不是物理题？”、“谁不知道物料守恒能量守恒？说说容易真让你靠这俩写状态方程你不炸了吗？”，是的，老师也知道，所以考卷上给方程组了，这个时候并不是万事大吉，题干一段英文你只需要看数字和符号，对应好代入方程组即可，但是题干中符号未必是全的，别急，数字一定是全的呀，看看数字附近的英文即可，比如化学反应kC^2的k可能就叫某某rate，然后记一下线性化的公式，就是该点加其导数，以及状态方程ABCD里的内容长啥样，相信自控里你也学过，慢慢耐心求偏导然后代入计算即可；**

**然后再说串级前馈比值均匀分程超弛选择，这一串是不会有什么计算的，它们的英文名你需要记住，否则你不知道问的哪个，然后每种方法你只需要会画实物示意图（就是有TT/TC/FF/FC/FT的那个图，记得要有箭头）以及流程框图，画图正确熟练足矣，这里甚至不需要写英文句子，当然了每种方法里细分可能不止一张图，也可能只有一张示意图没有框图，这里边可能还涉及气开气关以及控制器正反作用的选择，前者的判断就是当控制信号为0即“没气”时，这个阀出于安全考虑，应该是开还是关的，那么这个阀就是气关的或者是气开的，从名称上看是反着对应的，后者的判断原则就是闭环的一圈中“正反作用乘积为反（反反得正）”、“K的乘积为正”、“控制器的K正则控制器反作用，反之K负则控制器正作用”三条；**
